# Glance In Tailors releases

This repository distributes signed Windows installers and update manifests for Glance In Tailors Manager.

Download the installer from Releases. Existing configured installations can use Settings > App Updates.

Customer databases, backups, WhatsApp authentication, source code, private signing keys and passwords are not stored here. Shop data and credentials stay locally on the user's PC.

Release assets consist only of the versioned Windows setup EXE, its updater signature, latest.json and SHA256SUMS. A Tauri updater signature is separate from Windows Authenticode code signing.

Consult each release's notes and verification limitations before deployment. A successful software build alone is not a live WhatsApp delivery or clean-Windows acceptance test.
